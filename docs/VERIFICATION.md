# Проверки демонстрационной копии

Последние зафиксированные проверки приложения выполнены 8 ноября 2026 года. Охват: локальный запуск, публичные данные и изображения, главная, каталог предметов и курсов, статьи и изоляция демонстрации.

## Технические проверки

| Проверка | Результат |
| --- | --- |
| Подготовка базы | `demo.py setup` выполняет миграции и заполнение собственной SQLite. Ссылка `backend/public/storage` ведёт на локальное хранилище копии |
| Данные | 14 предметов, 64 курса, 8 преподавателей, 18 отзывов, 6 вопросов и 3 полные статьи с авторами. Пользователей, заказов и уроков нет |
| Серверные тесты | 24 теста, 111 проверок: `DemoPublicApiTest`, `SellableTariffTest`, `LessonBodyContractTest`, `RbacLegacyRoleMapTest` |
| Клиентская часть | Прошли все 609 тестов, линтер, `check:standards` и проверка типов TypeScript |
| Сборка | Сборка Next.js прошла при остановленном сервере разработки |
| Изображения | Проверены загрузка и соответствие хешам 225 изображений главной и 11 изображений статей |
| Ограничение записи | Тесты подтверждают ответ 403 на запросы изменения данных до выполнения бизнес-логики |
| Исходящие HTTP запросы | Тест подтверждает блокировку запроса Laravel без тестовой подмены |

Тесты статей проверяют список и детали всех трёх публикаций, поиск, ответ для неизвестной публикации, повторное заполнение базы, соответствие локальных медиа снимку и отсутствие внешних адресов изображений в HTML статей.

Команды запуска проверок находятся в [README](../README.md#проверки-и-ограничения). Полный набор серверных тестов в демо не проверен: часть зависит от исключённых классов заполнения базы, приватных данных, служебных команд, PostgreSQL или внешних сервисов. Ссылки на такие тесты в README позволяют изучить проверяемые ими сценарии.

## Проверка состава копии

Источники данных и изображений, выбранные поля и SHA256 записаны в [public-homepage.json](../backend/database/demo/public-homepage.json) и [public-articles.json](../backend/database/demo/public-articles.json). [FILE_INVENTORY.json](FILE_INVENTORY.json) содержит перечень файлов, [PUBLIC_COPY.md](PUBLIC_COPY.md) описывает состав и отличия демонстрации.

Для проверки файлов и объектов Git предусмотрен сканер:

```sh
python3 scripts/scan-public-copy.py --self-test
python3 scripts/scan-public-copy.py
python3 scripts/scan-public-copy.py --history
```

Сканер проверяет отслеживаемые файлы, а с `--history` также все объекты Git, включая недостижимые. Исключения привязаны к точному пути, digest совпадения и blob. Его набор детекторов ограничен: успешный результат не гарантирует отсутствия всех возможных секретов или уязвимостей.

## Границы проверки

В демонстрации не проверены реальные платежи и webhooks, воспроизведение Kinescope, защищённые учебные файлы, SMTP, подтверждение телефона через исходящий звонок пользователя, IMAP, рабочее S3, административные записи, ограничения PostgreSQL и поведение под нагрузкой. Видео представлены постерами, открытые PDF доступны по ссылкам на staging. Эти проверки не подтверждают готовность всей коммерческой LMS к эксплуатации.

# Состав демонстрационной копии

Копия содержит клиентскую и серверную части коммерческой образовательной платформы: модели, сервисы, миграции, фабрики, типы, компоненты, большинство тестов и файлы фиксации версий зависимостей. Для локального запуска включены публичные материалы школы. Охват проверок описан в [VERIFICATION.md](VERIFICATION.md).

## Публичные материалы главной

Содержание получено 8 ноября 2026 года только чтением открытой [главной staging](https://staging.christmedschool.com/) и её публичных API. Рабочие базы, исходные классы заполнения базы и приватное хранилище для этого переноса не использовались.

| Набор | Сохранено в локальном снимке |
| --- | --- |
| Каталог | 14 предметов и 64 курса: названия, ключи маршрутов, краткие названия курсов и публичная цена |
| Команда | 8 преподавателей: публичное имя, ключ маршрута, подпись на главной и ссылка на локальный вариант изображения |
| Отзывы | 18 записей: публичное имя, текст, дата, связь с предметом и курсом, изображение автора и публичная страница происхождения |
| FAQ | 6 вопросов: ключ маршрута, вопрос, ответ и категория |
| Статические материалы | Видимые тексты, контакты, ссылки на документы, иллюстрации и варианты изображений для разных экранов |

Точные URL и списки выбранных и исключённых полей находятся в `sources` файла [public-homepage.json](../backend/database/demo/public-homepage.json). Его `assets` содержит 225 изображений общим размером 14 855 843 байта, с исходным URL, локальным путём, назначением, SHA256 и размером каждого файла. В их числе портреты команды, изображения отзывов, иллюстрации главной и две страницы лицензии. Изображения-заглушки вне этого набора отмечены в инвентаре.

Адреса публичных изображений отзывов в объектном хранилище сохранены как сведения о происхождении в снимке. При запуске изображения копируются из `backend/database/demo-media` в собственное локальное хранилище и отдаются локально. Рабочее подключение S3 не требуется. Публичные имена команды и авторов статей хранятся в `ContentAuthor`, имена авторов отзывов в отзывах; это редакционные записи. Учётные записи в тестовых данных вымышленные.

Бинарные видео и PDF не импортированы. Первый экран и мобильный промоблок показывают статичные изображения. Ссылки на оферту, политику и PDF лицензии ведут на фактические публичные URL staging. Просмотр двух изображений лицензии на главной сохранён. Закрытые уроки, задания и учебные файлы не переносились; пользователей, заказов и уроков в демонстрационной базе нет.

## Полные публичные статьи

[public-articles.json](../backend/database/demo/public-articles.json) содержит три полные публикации школы из открытого API staging. Дата снимка: 8 ноября 2026 года.

| Статья | Публичный автор |
| --- | --- |
| Развитие сердца | Никита Лагутин |
| Почему в биохимии нужны клинические боксы: как теория становится врачебной практикой | Елена Лазарева |
| Биосинтез мочевины и его этапы | Юлия Беляева |

Сохранены весь текст и HTML структура публикаций, заголовки, таблица, связь с предметом, даты, публичные имена авторов, обложки и портреты. Первая статья содержит две иллюстрации внутри текста. Из HTML удалены только обёртки доставки `picture/source`; адреса изображений заменены локальными. Редакционный текст не переписывался. Пустые вложения, рекомендации, идентификаторы исходной базы и варианты изображений не импортировались.

Снимок перечисляет выбранные поля, исходные страницы и API, дату, SHA256 полученных ответов и исходных тел публикаций. Для 11 оригинальных изображений общим размером 1 030 997 байт записаны URL, локальный путь, размер и SHA256. `DemoSeeder` проверяет хеши перед копированием в локальный storage. Содержание, обложки, фотографии авторов и иллюстрации работают без внешнего API и S3. Снимок не обновляется автоматически; ссылки внутри редакционного текста могут вести на внешние публичные страницы.

## Исключения и локальные отличия

Не включены рабочие `.env`, базы, дампы, журналы, резервные копии, приватные загрузки, внутренние инструкции и память, закрытые документы по архитектуре и эксплуатации, команды развёртывания и переноса данных, материалы прежней системы, исходники дизайна и выгрузки таблиц. Исходные классы заполнения базы заменены собственными демонстрационными данными. Исключены `ArticleExistingCorpusRoundTripTest`, `NormalizeImportedAuthorNamesTest` и их приватные тестовые данные. Остальные исходные тесты сохранены для изучения; полный серверный набор в этой копии не проверен.

Локальный режим использует собственные SQLite и storage, файловые кеш и сессии, синхронную очередь и порты 3100/8100. Каждый `demo.py setup` пересоздаёт только демонстрационную базу через `migrate:fresh`, затем заполняет её локальными снимками публичного содержания. Ссылка публичного storage проверяется на принадлежность этой копии. Одна миграция, разрешающая `NULL` в email, адаптирована для SQLite. Эквивалентность PostgreSQL этим не подтверждается.

Демонстрационный режим блокирует HTTP запросы на изменение данных и исходящие HTTP запросы Laravel. Рабочие платежи, Kinescope, SMTP, подтверждение телефона звонком, IMAP и S3 не подключены; планировщик и отдельные обработчики очередей не запускаются. Публичные внешние ссылки доступны в браузере. Уведомление о демонстрации размещено после содержимого страницы, чтобы сохранить первый экран школы.

## Файлы и права

[FILE_INVENTORY.json](FILE_INVENTORY.json) перечисляет включённые файлы и способ их подготовки. Происхождение публичных изображений подробно записано в снимке данных; ограничения проверок описаны в [VERIFICATION.md](VERIFICATION.md). Тексты лицензий шрифтов OFL и указания авторства иконок сохранены.

Владелец разрешил использовать публичные тексты, имена и изображения школы для этой демонстрации. Это разрешение не предоставляет читателю лицензию на открытое использование коммерческого кода, бренда и материалов.

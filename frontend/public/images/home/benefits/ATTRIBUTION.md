# Иллюстрации преимуществ

Текущие четыре SVG используются как декоративные CSS-маски. Цвет задаётся semantic-токенами сайта; `viewBox` нормализован по видимому рисунку, квадратные intrinsic-размеры удалены для общей высоты иллюстраций.

| Файл | Источник |
|---|---|
| `platform-internet.svg` | Передан владельцем: `internet-connection-1-svgrepo-com.svg`. Контур облегчён SVG-фильтром. |
| `program-diploma.svg` | Передан владельцем: `diploma-with-seal-svgrepo-com.svg`. Внешняя рамка заменена равномерным stroke со скруглениями, печать сохранена. |
| `feedback-comments.svg` | Выбран владельцем: https://www.svgrepo.com/download/513147/comments.svg . Получен через https://www.svgrepo.com/show/513147/comments.svg . Геометрия сохранена. |
| `payment-installment.svg` | Передан владельцем: `loan-interest-time-value-of-money-effective-svgrepo-com.svg`. Геометрия сохранена. |

SVG содержат отметки SVG Repo / SVG Repo Mixer Tools. Точные страницы и индивидуальные лицензии трёх переданных файлов не предоставлены; сами файлы не включают условия лицензий. До внешней публикации требуется подтвердить источник и условия использования каждого ассета. Локальная проверка интерфейса не подтверждает эти права.

Неиспользуемые варианты иллюстраций и отвергнутый скриншот исключены из публичных ассетов. Они не загружаются текущим блоком.
